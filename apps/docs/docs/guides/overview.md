# Guides

Short, task-oriented instructions for operating a Tentacrawl deployment: routing traffic through a proxy, managing installed extensions, writing multi-step DSL flows, and running the stack in Docker. If you're looking to change *how* Tentacrawl behaves rather than how to run it, see [Extending Tentacrawl](/extending/overview) instead.
